# Tasks: Configure web boot presentation

Commands below are the harness commands that exist in the root `package.json` of this repository; this workspace has no turbo tasks, and `packages/client/web` declares no scripts of its own. Run every command from the repository root.

## 1. Presentation resolver

- [x] 1.1 Add `packages/client/web/src/boot-presentation.ts` with the exported public `BootPresentation` input type (`wordmark`, `loading`, `failure`, `failureExplanation`, `lang`, `dir`, `cssVariables`) and a `resolveBootPresentation(config: unknown)` function that returns a fully populated readonly record. Document the module contract in the module JSDoc, import nothing outside the package, and keep the fixed bounds as literals: 256 characters for `wordmark`, 1024 for `loading`/`failure`/`failureExplanation`, 35 for `lang`, 256 for a color value. Verify with `pnpm typecheck` (the `check:types` equivalent here is `typecheck:contracts-ready`, which runs `tsc -b tsconfig.client.json`), reporting no type error.
- [x] 1.2 Implement per-field normalization and rejection: non-empty trimmed strings only, over-long strings treated as absent rather than truncated, `dir` limited to `ltr`/`rtl`/`auto`. Read each known field directly with `try`/`catch` around the read, never enumerate the object's keys, never recurse into nested objects, and never invoke a supplied field. Verify with a focused test asserting each rejection path returns the documented default and that no call throws.
- [x] 1.3 Implement the closed color allowlist: exactly `--dsh-boot-bg`, `--dsh-boot-label-primary`, `--dsh-boot-label-secondary`, `--dsh-boot-label-tertiary`, `--dsh-boot-border`, and `--dsh-boot-brand`, read by name with no key enumeration and accepted only when the value is a non-empty string of at most 256 characters that matches the D1 grammar in `design.md` decision 2 and then passes `CSS.supports('color', value)`. Verify with a focused test covering an accepted 3/4/6/8-digit hex, an accepted `rgb`/`hsl`/`hwb`/`lab`/`lch`/`oklab`/`oklch` numeric body, an accepted named color including `transparent` and `grey`, and an accepted `color()` with each of the nine predefined spaces; plus a rejected name, a non-string/empty/over-long value, a `url(...)` value, a `var(...)`/`env(...)`/`attr(...)` value, a CSS-wide keyword, `currentColor`, a system color, a comment, an escape, a nested relative-color function, an angle unit, `none`, an exponent form, `calc(...)`, and a read that raises.
